TikTok Live Reader

Add-on ini terhubung ke siaran TikTok Live dan mengekstrak informasi secara real-time. Add-on menggunakan library Python TikTokLive untuk mengakses siaran live tertentu. Fitur-fitur berikut didukung:
  • Menyimpan data hasil ekstraksi ke dalam file teks. Secara default, file dibuat di folder Documents\TikTok live.
  • Mengarsipkan sesi live yang telah selesai dalam subfolder Backups, berdasarkan tanggal, waktu, dan host.
  • Melacak peristiwa: komentar, pengikut baru, hadiah (gift), likes, share, pengunjung, dan permintaan tamu.
  • Repost, anggota baru klub penggemar, dan jeda live juga dicatat.
  • File events yang dapat merekam berbagai jenis data secara bersamaan.
  • Notifikasi audio untuk peristiwa terpilih, seperti komentar baru, hadiah, dll.
  • Statistik siaran: menampilkan jumlah penonton saat ini, total pengunjung sesi, total likes, pengikut baru, dan diamond yang terkumpul.
  • Statistik juga menunjukkan durasi live serta jumlah komentar, share, dan hadiah.
  • Peringkat Top Gifters: mengurutkan pengguna dari yang paling aktif hingga yang paling sedikit berdasarkan diamond yang dikirim.
  • Peringkat Top Likers: mengurutkan pengguna berdasarkan total likes selama siaran.
  • Merekam live sebagai file video atau audio, yang secara default disimpan di folder Videos\TikTok live.
TikTok Live Reader membantu host atau penonton memantau data penting siaran tanpa alat eksternal. Data disimpan dalam file teks yang terletak di folder Documents\TikTok live dan dapat ditinjau kembali nanti. Add-on mengekstrak tipe data berikut ke dalam file terpisah:
  • comments.txt - Mencatat semua komentar yang terdeteksi selama live beserta timestamp.
  • followers.txt - Mencatat semua pengguna baru yang mengikuti kreator selama sesi berjalan.
  • gifts.txt - Mencatat semua hadiah yang diterima: pengguna, jenis hadiah, jumlah, dan timestamp.
  • likes.txt - Menunjukkan siapa yang memberi like, kapan, dan berapa kali.
  • requests.txt - Mencatat semua permintaan bergabung yang dikirimkan kepada host.
  • shares.txt - Mencatat pengguna yang membagikan siaran live beserta timestamp. Setiap baris menyebutkan apakah pengguna membagikan atau memposting ulang live.
  • stats.txt - Menampilkan penonton saat ini, pengunjung sesi, total likes, pengikut baru, dan total diamond. Juga mencakup durasi live dalam jam dan menit, serta jumlah komentar, share (termasuk repost), dan hadiah.
  • top gifters.txt - Peringkat pengguna yang mengirim hadiah, dari yang paling aktif sampai paling sedikit.
  • top likes.txt - Peringkat pengguna berdasarkan total likes.
  • visitors.txt - Mencatat semua pengunjung yang masuk selama sesi berjalan beserta timestamp.
  • events.txt - Terletak di antara file komentar dan pengikut selama navigasi keyboard, file ini mencatat berbagai jenis peristiwa yang ditentukan dalam pengaturan. Tujuannya adalah untuk melacak komentar, anggota klub penggemar, pengikut, hadiah, likes, permintaan, share, atau pengunjung dengan mudah di satu tempat. Setiap jeda dan kelanjutan live juga dicatat di events.txt.

Pengaturan

TikTok Live Reader memiliki jendela pengaturan sendiri, yang dapat dibuka dengan pintasan NVDA+Shift+Control+L. Jendela ini memiliki 5 tab:

Umum

Bagian ini mencakup pengaturan berikut:
  • Nama pengguna - Masukkan username host TikTok tanpa simbol @.
  • Lokasi file teks - Pilih tempat penyimpanan file teks. Lokasi default adalah Documents\TikTok live. Perubahan berlaku saat koneksi berikutnya.
  • Bersihkan file teks saat startup - Menghapus isi file teks saat add-on dimulai.
  • Bersihkan nama pengguna - Opsi ini menghapus elemen yang tidak perlu dari nama pengguna. Banyak pengguna TikTok menggunakan emoji dan simbol Unicode yang menghambat screen reader. Saat aktif, nama hanya akan berisi huruf Latin dan Sirilik, angka, dan tanda baca. Jika tidak ada yang tersisa dari sebuah nama, username TikTok pengguna tersebut yang digunakan.
  • Arsipkan setiap sesi live - Menyalin setiap sesi yang selesai ke subfolder bertanggal dalam Backups saat add-on dimatikan.
  • Jumlah percobaan koneksi - Menentukan berapa kali add-on mencoba tersambung ke siaran live.

Peristiwa

Bagian ini berisi kotak centang untuk menentukan data mana yang dicatat di events.txt (Komentar, Anggota klub penggemar, Pengikut, Hadiah, Suka, Permintaan, Berbagi, dan Pengunjung).

Bicara otomatis

Bagian ini menentukan data mana yang diumumkan saat fungsi bicara otomatis aktif. Aktifkan dengan NVDA+Shift+Control+S atau kotak centang "Bacakan peristiwa yang dipilih secara otomatis". Saat aktif, peristiwa tertentu dapat dipilih untuk dibacakan otomatis (misalnya "Pengikut baru: Username"). Baik bicara otomatis aktif maupun tidak, add-on selalu mengumumkan saat live dijeda, saat live dilanjutkan, dan saat live berakhir.

Suara

Bagian ini menentukan peristiwa live mana yang akan memicu isyarat audio pendek. Agar fitur ini berfungsi, Anda harus mengaktifkan opsi "Putar suara untuk peristiwa yang dipilih" terlebih dahulu. Setelah diaktifkan, kotak centang akan muncul, disusun dalam urutan yang persis sama dengan dua bagian sebelumnya. Anda juga dapat mengaktifkan/menonaktifkan suara menggunakan pintasan NVDA+Shift+Control+P. Opsi berikut juga tersedia:
  • Volume audio - Penggeser ini menentukan tingkat kekerasan suara notifikasi peristiwa.
  • Pelajari suara - Memutar deskripsi suara agar pengguna dapat mendengarnya terlebih dahulu.
Suara dan pesan diputar sesuai urutan kedatangannya, dengan jeda satu detik di antaranya, bahkan saat live ramai. Fungsi suara dan bicara otomatis bekerja secara independen.

Rekaman live

Bagian ini menentukan cara sesi direkam. Pengaturan berikut tersedia:
  • Mulai merekam saat terhubung - Perekaman dimulai otomatis saat add-on terhubung ke live. Secara default opsi ini nonaktif. Selama add-on terhubung, perekaman dapat dimulai dan dihentikan dengan NVDA+Shift+Control+E.
  • Format - Pilih antara MP4 (720p) dan MP3 (192 kbps).
  • Folder rekaman - Pilih tempat penyimpanan rekaman. Lokasi default adalah Videos\TikTok live.
Perekaman memerlukan FFmpeg, sebuah program gratis. Saat perekaman diaktifkan untuk pertama kali, add-on menanyakan apakah FFmpeg akan diunduh (sekitar 109 MB). FFmpeg diinstal di folder konfigurasi NVDA.

Cara menggunakan add-on

Tekan NVDA+Shift+Control+T dan klien TikTok Live Reader akan mencoba terhubung. Status koneksi diumumkan otomatis. Setelah terhubung, hotkey berikut tersedia:
  • Control+Shift+Panah Kanan - File berikutnya (misalnya Comments, Events, Followers, dll).
  • Control+Shift+Panah Kiri - File sebelumnya.
  • Control+Shift+Panah Bawah - Item berikutnya di file saat ini (misalnya komentar, like, share).
  • Control+Shift+Panah Atas - Item sebelumnya.
  • Control+Shift+Home - Pilih item pertama di file saat ini.
  • Control+Shift+End - Pilih item terakhir.
  • NVDA+Shift+Control+V - Melaporkan jumlah penonton saat ini.
  • NVDA+Shift+Control+S - Mengaktifkan atau menonaktifkan bicara otomatis.
  • NVDA+Shift+Control+P - Mengaktifkan atau menonaktifkan suara.
  • NVDA+Shift+Control+R - Menghapus isi file teks setelah konfirmasi.
  • NVDA+Shift+Control+E - Memulai atau menghentikan rekaman live.
Tekan NVDA+Shift+Control+T untuk mengakhiri sesi add-on. Data yang terkumpul tersedia di folder file teks yang dipilih. Jika pengarsipan sesi diaktifkan, sesi yang selesai disimpan dalam subfolder Backups.

Catatan

  • Membuka pengaturan menonaktifkan sementara bicara otomatis dan suara, tetapi pencatatan data tetap berlanjut di latar belakang.
  • Jika username diubah di pengaturan, add-on akan mencoba terhubung ke pengguna baru setelah disimpan.
  • Saat pembersihan file otomatis dinonaktifkan, file akan tetap berisi data dari siaran live terakhir. Jika Anda ingin menghapusnya di awal sesi saat ini, tekan NVDA+Shift+Control+R.
  • Jika pembersihan otomatis dinonaktifkan, add-on mengingat posisi terakhir Anda di file (misalnya baris 45 di komentar).

Batasan

  • Daftar penonton lengkap tidak dapat ditampilkan karena library TikTokLive tidak melaporkan saat pengguna keluar.
  • Peringkat berdasarkan durasi tonton tidak dapat dibuat karena alasan yang sama.
  • Nama hadiah dilaporkan dalam bahasa Inggris karena jumlahnya terlalu banyak dan terlalu sering diperbarui untuk diterjemahkan secara layak.
  • Live yang dibatasi usia tidak dapat direkam karena TikTok hanya memberikan videonya kepada penonton yang masuk ke akun.

Daftar Perubahan

Versi 2.0

  1. Live kini dapat direkam sebagai file video atau audio. Perekaman memiliki tab pengaturan sendiri dan dapat dimulai atau dihentikan dengan NVDA+Shift+Control+E.
  2. Repost kini diperlakukan seperti share biasa, dan setiap tindakan disebutkan di shares.txt.
  3. Menambahkan kotak centang Anggota klub penggemar di bagian Peristiwa, Bicara otomatis, dan Suara. Anggota baru klub penggemar dapat dicatat di events.txt, diumumkan, dan ditandai dengan suara tersendiri.
  4. Jeda dan kelanjutan live selalu dicatat di events.txt dan diumumkan.
  5. Suara untuk share telah diganti.
  6. stats.txt kini menampilkan durasi live serta jumlah komentar, share, dan hadiah.
  7. Permintaan bergabung kini mengumumkan siapa yang masuk antrean, meskipun pengguna tersebut belum terdeteksi sebelumnya. Permintaan yang diajukan lagi setelah dibatalkan juga dikenali.
  8. Library TikTokLive diperbarui ke versi 7.0.1.
  9. Versi minimum NVDA yang didukung sekarang adalah 2026.1.
  10. Memperbaiki entri komentar, share, dan hadiah yang hilang atau ganda.
  11. Perbaikan bug dan peningkatan kinerja.

Versi 1.8

  1. Menambahkan konfirmasi sebelum menghapus semua file dengan NVDA+Shift+Control+R.
  2. Menambahkan pengaturan untuk memilih lokasi file teks. Lokasi default tetap Documents\TikTok live.
  3. Menambahkan opsi untuk mengarsipkan setiap sesi live dalam subfolder bertanggal di Backups.
  4. Pengaturan add-on kini disimpan di folder utama NVDA agar tetap tersimpan saat TikTok Live Reader diperbarui.
  5. Versi minimum NVDA yang didukung sekarang adalah 2025.1.
  6. Melakukan refaktor dan optimasi kode untuk meningkatkan stabilitas dan memperbaiki bug.

Versi 1.6

  1. Add-on sekarang kompatibel dengan NVDA 2026.1.
  2. Pengaturan di bagian Events sekarang hanya berlaku untuk file events.txt. Ini menentukan jenis data apa saja yang akan dicatat di dalamnya.
  3. Bagian Sounds telah ditambahkan, dengan opsi pengalih utama "Play sounds for the selected events".
  4. Sebagai hasilnya, fungsi bicara otomatis (auto-speak), pemutaran suara, dan perekaman data dalam file events bekerja secara independen satu sama lain.

Versi 1.5

  1. Logika untuk memuat dan mematikan add-on telah distabilkan.
  2. Migrasi ke NVDA addon template untuk otomatisasi dan lokalisasi yang lebih baik.
  3. Logika pencatatan untuk likes, share, dan follows telah ditingkatkan.
  4. Opsi Auto speak sekarang dipatuhi; pengumuman dimulai 10 detik setelah koneksi berhasil.
  5. Tab Auto speak sekarang secara dinamis menyembunyikan pilihan peristiwa kecuali fungsi utama diaktifkan.
  6. Memperbaiki bug di mana suara dan pengumuman dimainkan segera setelah restart add-on.
  7. Menambahkan pintasan NVDA+Shift+Control+P untuk mengaktifkan/menonaktifkan suara selama sesi aktif.
  8. Menambahkan tombol akses (Alt + huruf) untuk semua pengaturan.
  9. Logika slider Audio volume dioptimalkan. Labelnya sekarang adalah Volume.
  10. Pengaturan sekarang disimpan secara dinamis. Pencatatan latar belakang berlanjut saat jendela pengaturan terbuka.
  11. Koneksi otomatis ke pengguna baru jika diubah dalam sesi aktif.
  12. Menambahkan dukungan untuk melacak permintaan bergabung. Disimpan dalam file requests.txt.
  13. Opsi "Requests" baru di pengaturan dan notifikasi suara baru untuk peristiwa tersebut.
  14. Menambahkan validasi input username: minimal dua karakter dan hanya boleh berisi huruf Latin, angka, titik, dan garis bawah.
