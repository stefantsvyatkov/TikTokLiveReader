• Text files destination - Sets the folder the text files are written to. By default this is Documents\TikTok live. Use the Browse button to pick a different folder. The field cannot be typed into, so an invalid path can never be entered. A new location takes effect the next time the add-on connects, so an active session is never interrupted.
  • Archive each live session - When enabled, a Backups folder is created inside the text files destination. When the add-on is switched off, each finished session is copied into its own subfolder there, named with the date, time and host, for example 2026-08-15 21-40-03 username. Sessions therefore appear in chronological order, with the newest at the bottom. The original text files stay where they are. If a connection failed and nothing was collected, no folder is created.
  • NVDA+Shift+Control+R - Clears content of the text and temporary files. A confirmation question is shown first, so the command cannot be triggered by accident.

    • Version 1.7

    1. A confirmation question is now shown before all files are deleted with NVDA+Shift+Control+R. The aim is to prevent the command from being triggered by accident.
    2. A setting has been added for choosing where the text files are stored. The default location is still Documents\TikTok live, but it can now be changed by the user.
    3. An Archive each live session option has been added. A Backups folder is created in the main text files directory. Subfolders holding the text files of every past live session are added to it. Their names contain the date, time and host.
    4. Refactoring and optimisation of part of the code, improved stability, and several bugs fixed.
  • If the text files folder becomes unreachable, for example when it is on a removable drive that has been unplugged, the add-on announces that the folder is not available while you browse the records. The next time it starts, it automatically falls back to the default folder.
  • The minimum supported NVDA version is now 2025.1.
