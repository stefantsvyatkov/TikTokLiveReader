• Text files destination - Menentukan folder tempat file teks disimpan. Secara bawaan lokasinya adalah Documents\TikTok live. Gunakan tombol Browse untuk memilih folder lain. Kolom ini tidak dapat diketik secara manual, sehingga lokasi yang tidak valid tidak dapat dimasukkan. Lokasi baru mulai berlaku pada koneksi berikutnya, sehingga sesi yang sedang aktif tidak pernah terputus.
  • Archive each live session - Jika diaktifkan, folder Backups akan dibuat di dalam lokasi file teks. Saat add-on dinonaktifkan, setiap sesi yang telah selesai disalin ke subfolder tersendiri di dalamnya, dengan nama yang berisi tanggal, waktu, dan host, misalnya 2026-08-15 21-40-03 username. Dengan demikian sesi tersusun secara kronologis, dan yang terbaru berada di paling bawah. File teks asli tetap berada di tempatnya. Jika koneksi gagal dan tidak ada data yang terkumpul, folder tidak akan dibuat.
  • NVDA+Shift+Control+R - Menghapus isi file teks dan file sementara. Pertanyaan konfirmasi akan ditampilkan terlebih dahulu, sehingga perintah ini tidak dapat dipicu secara tidak sengaja.

    • Versi 1.7

    1. Pertanyaan konfirmasi kini ditampilkan sebelum semua file dihapus dengan NVDA+Shift+Control+R. Tujuannya adalah mencegah perintah ini dipicu secara tidak sengaja.
    2. Pengaturan untuk memilih lokasi penyimpanan file teks telah ditambahkan. Lokasi bawaannya tetap Documents\TikTok live, tetapi kini dapat diubah oleh pengguna.
    3. Opsi Archive each live session telah ditambahkan. Folder Backups dibuat di dalam direktori utama file teks. Subfolder yang berisi file teks dari setiap sesi live sebelumnya ditambahkan ke dalamnya. Namanya berisi tanggal, waktu, dan host.
    4. Refaktorisasi dan optimisasi sebagian kode, stabilitas yang ditingkatkan, serta perbaikan beberapa bug.
  • Jika folder file teks tidak dapat dijangkau, misalnya ketika berada di media lepasan yang telah dicabut, add-on akan mengumumkan bahwa folder tersebut tidak tersedia saat Anda menelusuri catatan. Pada penggunaan berikutnya, add-on secara otomatis kembali ke folder bawaan.
  • Versi NVDA minimum yang didukung kini adalah 2025.1.
